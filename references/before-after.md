# 수정 전 화면 보여 주기

수정 전 동작은 실제 화면이나 기록으로 확인한 경우에만 설명한다.

## Vite 개발 서버에서 같은 창으로 전환

Vite가 서빙하는 소스 모듈 요청을 가로채 수정 전 사본으로 돌린다.

```js
openBrowser({
  swap: { "/src/path/Screen.tsx": "/<사본 경로>/Screen.tsx" },
  swapBase: process.env.DEMO_URL,
});
```

사본도 Vite가 서빙해야 변환이 적용된다. 앱 폴더 안의 Git 무시 디렉터리에 둔다. 상대 경로로 가져오는 모듈이 있다면 필요한 폴더를 함께 복사한다.

기준 커밋에서 파일을 꺼낼 때는 다음 명령을 쓸 수 있다.

```sh
git -C <저장소> archive <기준 커밋> <필요한 경로> | tar -x -C <임시 폴더>
```

## 다른 개발 서버에서 비교

기준 커밋을 별도 작업 폴더에 꺼내 다른 포트로 실행한다. 데모 스크립트는 수정 전 장면에서 그 주소로 이동한다.

```sh
git worktree add <임시 폴더> <기준 커밋>
```

종료 후 별도 서버를 끄고 `git worktree remove <임시 폴더>`로 작업 폴더를 지운다. 서비스에 따라 의존성 설치와 환경 변수 설정이 필요하다.

## 화면을 띄울 수 없을 때

검증 기록, 이슈, 스크린숏으로 확인한 내용만 설명한다. 기억이나 추측으로 수정 전 동작을 단정하지 않는다.
